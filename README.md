# গেজেটেড কর্মকর্তার বেতন বিল ফরম

এই HTML ফাইলটি গেজেটেড সরকারি কর্মকর্তাদের বেতন বিল পূরণের জন্য ব্যবহার করা যাবে।

## ব্যবহার

1. `গেজেটেড কর্মকর্তার বেতন বিল ফরম.html` ব্রাউজারে খুলুন।
2. প্রয়োজনীয় তথ্য পূরণ করুন।
3. প্রাতিষ্ঠানিক/অপারেশন কোডে ১৩ ডিজিট লিখুন।
4. প্রয়োজন হলে পৃষ্ঠা ২ অন্তর্ভুক্ত করার checkbox পরিবর্তন করুন।
5. PDF-এর জন্য **PDF করুন / প্রিন্ট** চাপুন।
6. Word ফাইলের জন্য **DOCX ডাউনলোড** চাপুন।

## সুবিধা

- ফরমের তথ্য স্বয়ংক্রিয়ভাবে সংরক্ষণ
- বেতন ও কর্তনের মোট হিসাব
- PDF/প্রিন্টের জন্য A4 layout
- ঐচ্ছিক দ্বিতীয় পৃষ্ঠা
- টেবিলের অর্থনৈতিক কোড ও বিবরণ সম্পাদনা
